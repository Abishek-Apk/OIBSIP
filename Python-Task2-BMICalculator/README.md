# BMI Calculator

## Task
Python Programming - Task 2

## Objective
A Python program that calculates Body Mass Index (BMI) based on the user's weight and height and classifies the result into a BMI category.

## Features
- Accepts weight in kilograms
- Accepts height in meters
- Calculates BMI
- Displays BMI rounded to 2 decimal places
- Classifies BMI as Underweight, Normal, Overweight, or Obese
- Validates numeric input
- Rejects negative or zero values

## BMI Formula

BMI = weight / (height²)

# Random Password Generator

## Task
Python Programming - Task 3

## Objective
A Python program that generates random passwords based on the user's selected length and character requirements.

## Features
- Accepts minimum password length
- Supports uppercase letters
- Supports numbers
- Supports symbols
- Generates random passwords
- Validates generated passwords
- Allows the user to generate another password
- Handles invalid length input

## Technologies Used
- Python
- random module
- string module

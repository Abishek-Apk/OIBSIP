# Basic Weather App

## Description

A simple Python command-line weather application that retrieves
current weather information for a city using the OpenWeather API.

## Features

- Search weather by city name
- Display temperature
- Display feels-like temperature
- Display humidity
- Display weather condition
- Handle invalid city names
- Support multiple city searches
- Exit the application using `exit`
- API key stored securely using a `.env` file

## Technologies Used

- Python
- Requests
- python-dotenv
- OpenWeather API

## Installation

Install the required packages:

pip install requests python-dotenv
